# Soundwave
A Tauri React TypeScript app that can download YouTube videos as MP3 or other audio files and store them in playlists to play later.

## Features
- YouTube searching and direct downloading from results
- Ability to download in MP3 and WAV format
- Create playlists

## Future plans
- More audio options: Choose from other formats, like OPUS, as well as bitrate.
- MP4 Support: Download your favorite videos as well
- Download Spotify, Apple Music, and YouTube Music files as well
